# HireTrack – Interview Process Tracking System

A web application to manage job descriptions and track candidates through the interview
stages: **Profiling → Screening → L1 Technical → L2 Technical → HR Round**.

The project lives in [`Capstone_HireTrack/`](Capstone_HireTrack/):

| Folder | Contents |
|---|---|
| [`backend/`](Capstone_HireTrack/backend) | Node.js + Express REST API, PostgreSQL (Prisma), JWT auth, email (SMTP), Jest tests |
| [`frontend/`](Capstone_HireTrack/frontend) | HTML, Tailwind CSS and JavaScript pages for HR, panel members and candidates |

Setup steps, features, API list and test results are in the
[project README](Capstone_HireTrack/README.md).

## Branches
- `develop` – daily work
- `main` – reviewed work, updated through pull requests from `develop`
